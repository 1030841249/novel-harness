# State Tracking Map

> 用途：上下文 Agent 按需加载的状态追踪规则图。Agent 本体只保留入口，本文件承载细则。

## 触发场景

| 场景 | 使用规则 |
|:-----|:---------|
| 写作前打包上下文 | 最小记忆包 |
| 章节写完后归档 | 状态快照更新 |
| 连续章节规划 | 线索热度 |
| 审稿检查状态矛盾 | 状态一致性对照 |

## 最小记忆包

只保留三类信息：

| 类型 | 保留条件 | 丢弃条件 |
|:-----|:---------|:---------|
| 当前状态 | 本章出场角色的能力、关系、位置、目标、公众形象 | 本章不出场且无影响 |
| 历史因果 | 本章会触碰、回收、误导或继续压住的伏笔/前史 | 纯背景设定 |
| 世界约束 | 本章涉及的规则、资源、时间、空间限制 | 本章不会使用 |

判断句：

```text
如果不知道这条信息，本章会写错吗？
会 -> 保留
不会 -> 摘要或丢弃
```

输出格式：

```text
角色状态：
- {角色}：{一句话当前状态，含最近变化}

相关伏笔/前史：
- {伏笔/前史}：{埋设细节或因果来源}，本章需要{触碰/推进/回收/压住}

世界约束：
- {约束}：{与本章直接相关的规则}
```

## 状态快照字段

| 文件 | 字段 |
|:-----|:-----|
| `projects/{项目}/状态/主角.md` | 身体、能力、处境、目标、关系、关键资源、位置、最近事件 |
| `projects/{项目}/状态/角色/{角色}.md` | 当前身份、当前能力、关键关系、公众形象、待回收伏笔、最近变化 |
| `projects/{项目}/状态/伏笔登记表.md` | 编号、埋下章节、内容、类型、预计回收、状态、实际回收 |
| `projects/{项目}/状态/线索热度.md` | 线索、状态、最近有效触碰、下一步处理、休眠原因 |
| `projects/{项目}/记忆/事件索引.md` | 章节、事件、涉及角色、影响 |
| `projects/{项目}/记忆/章节摘要/第N章.md` | 字数、核心冲突、主要进展、状态变化、伏笔、钩子 |

## 更新规则

| 更新对象 | 何时更新 | 规则 |
|:---------|:---------|:-----|
| 角色状态 | 每章写完后 | 只记录身份、能力、关系、公众形象、位置、目标的事实变化 |
| 伏笔登记 | 埋下/回收伏笔时 | 新伏笔追加；已回收标记实际章节 |
| 事件索引 | 重大事件发生时 | 只记录会影响后续理解的事件 |
| 章节摘要 | 每章完成后 | 200 字以内，不做评价 |
| 线索热度 | 每章完成后 | 有效推进、加压、改变关系或产生后果才算触碰 |

## 线索热度

| 状态 | 含义 | 处理 |
|:-----|:-----|:-----|
| `hot` | 当前驱动冲突的核心线 | 本章或下一章必须推进/加压 |
| `warm` | 近期活跃但非本章核心 | 2-5 章内有效触碰 |
| `cold` | 暂时休眠或快被遗忘 | 回归前先预热 |
| `archived` | 已关闭或已回收 | 不再进入最小记忆包 |

有效触碰：推进线索、施加压力、改变关系、产生后果、交代休眠原因。  
无效触碰：只提名字、空泛回忆、随机提及、无后果闲聊。

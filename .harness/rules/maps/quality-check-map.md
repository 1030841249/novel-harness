# Quality Check Map

> 用途：审稿 Agent、写作 Agent 和规划 Agent 按需加载的质量检查规则图。避免把完整清单写进 Agent 本体。

## 路由

| 审查目标 | 优先检查 |
|:---------|:---------|
| 单章正文 | 章节结构、场景目标、章尾、语言、连载连续性 |
| 黄金三章 | 开篇 300-500 字、卖点/危机可见、前三章追读理由 |
| 长篇连载 | 最近 5 章进展、爽点间隔、伏笔推进、故事引擎 |
| 短篇爽/虐文 | 虐爽分布、对话密度、证据链、结尾情绪落点 |
| 去 AI 味 | 可读性、表层重写度、总结腔、解释腔、情绪标签 |
| 大修判断 | 五维评分后选择 rewrite/compress/de_ai/polish |

## 通用质量门禁

| 维度 | 检查点 |
|:-----|:-------|
| 章节结构 | 开头有钩子；中段有推进；结尾落在变化上 |
| 章节推进 | 有核心事件；推进主线/关系/设定至少一项；删掉本章会影响理解 |
| 信息传递 | 没有大段设定说明；信息跟着冲突走；一章新概念不超过 3 个 |
| 场景 | 有目标、有阻碍、有变化；人物在做事，不只是在感觉 |
| 章尾 | 有危机/决定/发现/反转；不是总结式结尾 |
| 语言 | 无空洞抒情；无连续同情绪；对话区分人物身份；情绪用动作落地 |
| 微观胶水 | 信息衔接自然；必要时有符合人物和现场的动作、感知或环境承接，不机械补反应链 |
| 环境/吐槽/行动 | 环境不清单扫描；吐槽贴近现场；计划不并列无关目标；写作块有一个主要目标 |
| 连续性 | 未遗忘承诺/伏笔；没有突然塞大量新设定；故事引擎仍在运转 |
| 水分 | 无新信息对话、重复情绪、无推进长景物、无新视角回忆、连续无冲突 |

## 长篇专项

| 目标 | 检查点 |
|:-----|:-------|
| 黄金三章 | 第一章前 500 字有钩子；主角第一章出场；前三章至少 2 个爽点；每章结尾有悬念 |
| 节奏 | 最近 5 章有明确进展；爽点间隔不过长；连续 2 章以上无冲突需警告 |
| 人物 | 主角行为符合人设；配角有存在感；反派逼格匹配当前阶段 |
| 期待管理 | 两长一短不断；核心卖点贯穿；读者期待不能长时间不满足 |

## 五维评分

| 维度 | 看什么 | 低分处理 |
|:-----|:-------|:---------|
| 核心一致度 | 关键冲突、行动、动机是否前后一致 | `rewrite` |
| 表层重写度 | 句式、措辞是否套路化或 AI 化 | `de_ai` / `polish` |
| 格式一致度 | 段落、字数、开头结尾格式是否统一 | `polish` |
| 可读性 | 啰嗦、空泛总结、套路修辞、心理独白 | `de_ai` / `compress` |
| 逻辑连贯 | 设定、时间线、角色信息、因果链 | `rewrite` / `polish` |

策略选择：

| 主要问题 | 策略 |
|:---------|:-----|
| 核心一致度低 | `rewrite` |
| 字数超标或水分高 | `compress` |
| AI 腔重 | `de_ai` |
| 小问题多 | `polish` |

## 微观拼接感

正文出现“信息点完整但衔接发硬、人物直接进入分析、环境像清单、吐槽脱离现场、计划像待办事项”时，标记为 `de_ai` 或 `polish`，不要直接重写剧情。

本 Map 只负责发现和分级，不维护具体改写步骤。修正时路由到：

```text
.harness/skills/human-linguistics/rules/去AI味最小修改指南.md
```

禁止把“误判、动作、碎念、吐槽、环境确认”当成固定配方逐项补齐。

## 短篇专项

| 维度 | 标准 |
|:-----|:-----|
| 虐爽节奏 | 虐点间隔不超过全文 30%；最大爽点在 70%-85%；结尾有情绪落点 |
| 对话密度 | 对话占比 45%-65%；每千字 12-18 条；过低干、过高碎 |
| 复仇/打脸 | 主角冷静；反派更失控；证据分章释放；最终证据改变全局认知 |
| 结尾 | 具体动作/对话/画面收尾，禁止总结/反思 |

## 严重度

| 等级 | 定义 |
|:-----|:-----|
| `critical` | 设定冲突、动机崩坏、核心冲突错误、主角行为不可理解 |
| `high` | 字数明显偏离、节奏断档、章尾无钩子、AI 腔重 |
| `medium` | 句式重复、信息传递笨重、段落不顺、伏笔触碰不足 |
| `low` | 格式、措辞、局部表达瑕疵 |

# 创作管线

> 从构思到完稿，novel-harness 的完整创作流程。

---

## 默认单章陪写流水线

```
用户给出第 N 章目标或卡点
  │
  ▼
① 总编 / 规划 Agent — 定位卡点并激发思路
   ├─ 判断缺少目标、冲突、转折、场景还是表达
   ├─ 必要时提出 1-3 个定向问题
   └─ 给 2-3 个候选，等待用户确认
  │
  ▼
② 上下文 Agent — 打包当前上下文
   ├─ 主角状态（身体/能力/处境/位置/目标）
   ├─ 出场角色
   ├─ 活跃伏笔（标记超期）
   ├─ 风格参考（最近3章特征）
   └─ 约束提醒（⚠ 不能违反的规则）
  │
  ▼
③ 写作 Agent — 输出分块写作指引
   ├─ 接收上下文包 + 大纲
   ├─ 按篇幅拆成足量“空瓶”
   └─ 每瓶只说明一个主要发展和可填材料
  │
  ▼
④ 用户 — 逐块写作并人工精修
   ├─ 选择、调整或拒绝写作块
   ├─ 完成人物口气和具体表达
   └─ 遇到局部卡点时继续请求陪练
  │
  ▼
⑤ 审稿 Agent — 质量诊断
   ├─ 语感检查（human-linguistics）
   ├─ 情节检查（plot-review）
   ├─ 节奏检查（rhythm-review）
   └─ 题材检查（按需加载）
  │
  ▼
⑥ 用户确认定稿后，上下文 Agent — 归档
   ├─ 更新主角状态
   ├─ 更新伏笔登记表
   ├─ 更新事件索引
   ├─ 生成章节摘要
   └─ 按项目工作流归档
```

---

## 完整正文粗稿旁路

只有用户明确要求“直接生成完整初稿、写入正文文件或落盘”时进入：

```text
确认章节目标、人物视角和目标字数
  -> 上下文 Agent 打包
  -> 写作 Agent 生成“待人工精修粗稿”
  -> 用户阅读和修改
  -> 审稿 Agent 诊断
  -> 用户确认定稿
  -> 上下文 Agent 归档
```

AI 粗稿不是可直接上架的终稿。用户未确认前，不将粗稿中的新增设定和剧情变化写入长期状态。

## 200 万字创作周期

| 阶段 | 章节范围 | 核心任务 |
|------|---------|---------|
| 第一卷 | 第 1-30 章 | 建立世界观 + 主角初始成长 |
| 第二卷 | 第 31-80 章 | 扩大格局 + 引入势力冲突 |
| 第三卷 | 第 81-150 章 | 深化主线 + 伏笔集中回收 |
| 第四卷 | 第 151-250 章 | 世界观揭秘 + 格局升级 |
| 第五卷+ | 第 251 章+ | 终极冲突 + 收束全部线索 |

每卷结束后由规划 Agent + 上下文 Agent 做卷总结和下一卷大纲调整。

## 状态与记忆系统

### 状态文件（由上下文 Agent 自动维护，禁止手动修改）

| 文件 | 内容 | 更新时机 | 读取者 |
|------|------|---------|--------|
| `状态/主角.md` | 身体/能力/处境/位置/目标/关键资源 | 每章完成后 | 写作/规划/审稿 Agent |
| `状态/角色/{角色名}.md` | 配角状态/关系/已知信息 | 该角色出场后 | 写作/审稿 Agent |
| `状态/伏笔登记表.md` | 编号/内容/埋下章/预计回收章 | 每章完成后 | 规划 Agent |

### 记忆文件（由上下文 Agent 自动维护）

| 文件 | 内容 | 用途 |
|------|------|------|
| `记忆/事件索引.md` | 重大事件按章索引 | 快速定位历史事件 |
| `记忆/章节摘要/第N章.md` | 200 字章节概要 | 上下文包素材 |
| `记忆/风格参考.md` | 最近 5 章写作特征 | 风格一致性保持 |

### 上下文包（每次写作前临时生成）

```
━━ 上下文包 ━━
── 1. 当前任务 ──    ← 本章要写什么
── 2. 主角状态 ──    ← 主角精确的当前状态
── 3. 出场角色 ──    ← 本章涉及的角色
── 4. 活跃伏笔 ──    ← 未回收的伏笔（超期标记）
── 5. 风格参考 ──    ← 最近3章节奏特征
── 6. 约束提醒 ⚠    ← 不能违反的硬约束
```

### 生命周期

```
写作前                  用户写作/粗稿            用户定稿后
  │                      │                      │
  ▼                      ▼                      ▼
读取状态文件    →   Agent 只提供支架    →   更新状态文件
读取记忆文件    →   用户完成最终表达    →   更新记忆文件
打包上下文包    →   必要时生成粗稿      →   按项目流程归档
```
